## 两个平面，一套模型

<CardGrid>
	<Card title="控制平面" icon="setting">
		`guru-master` 提供运维 API、Worker API、用于推导配置并运行所有周期任务的 AMQP 钩子，
		以及负责调度它们的时钟 —— 一个二进制文件，四种模式。
	</Card>
	<Card title="数据平面" icon="rocket">
		`guru-worker` 负责终结监听器并转发流量，配置既可以来自本地 TOML 文件，
		也可以从 master 流式下发。
	</Card>
	<Card title="收敛式发布" icon="approve-check">
		每台服务器都保存 `desired`、`in_flight` 和 `applied` 三份快照，因此任何修订版本都不会在
		发布过程中丢弃流量。
	</Card>
	<Card title="一切皆 Processor" icon="puzzle">
		状态加上一个异步函数。每个查询、操作和消费者都是一个输入结构体，配一个
		`Processor` 实现。
	</Card>
</CardGrid>
